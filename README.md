Iris Flower Prediction 🌸

About the Project

This is a simple Machine Learning project that predicts the type of Iris flower using the K-Nearest Neighbors (KNN) algorithm.

Technologies Used

- Python
- Scikit-learn
- Iris Dataset

Features

- Takes sepal length and width as input.
- Takes petal length and width as input.
- Predicts the Iris flower species.

Installation

Install the required library:

py -m pip install scikit-learn

How to Run

Run the program using:

py main.py

Enter the flower measurements when prompted.

Output

The program predicts one of these flower types:

- Setosa
- Versicolor
- Virginica

Algorithm

K-Nearest Neighbors (KNN)
